# 会员积分商城（开发交付）

给研发对照的静态 H5，无后端。主流程与演示版相同，细节会继续改。

演示版（已冻结，勿改）：https://guiyx-dot.github.io/paper-shop/

## 在线地址

- 用户端：https://guiyx-dot.github.io/points-mall-spec/
- 商户后台：https://guiyx-dot.github.io/points-mall-spec/#/admin

积分状态存在打开者自己的浏览器里，与演示版数据互不影响。

## 本地运行

```bash
npm install
npm run dev
```

浏览器会打开 `http://127.0.0.1:5174/`。电脑端是手机外框预览，手机浏览器则全屏。
