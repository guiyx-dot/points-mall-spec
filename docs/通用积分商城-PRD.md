# 通用积分商城 PRD（给研发）

**对着原型看：** 本地打开后进 [http://127.0.0.1:5174/#/prd](http://127.0.0.1:5174/#/prd)。左边选页面，中间是原型，右边是这条规则。

状态：业务已对齐。对象：在现有数字中台 + 商户后台 + C 端会员上增加「通用积分」及积分商城，不推翻原有权益商品。

---

## 要解决什么

1. **合规**：金/券发完自动到账仍不合规。改为先发积分，用户自己到积分商城兑成权益后再使用。
2. **转型**：现有通用金 / 各类券是类现金，监管在收紧。希望用户去兑普通权益，而不是只拿类现金。

两套不能混账、混合同、混履约。本期在原商品体系新增商品 **通用积分**，服务费 **3%**（商户承担，不可调）；C 端再包一层积分商城。专用券继续走原来的权益商品。

---

## 和现有系统

中台仍是：权益中心 → 商品中心包装 → 商户商品配置分配给 4S。本期商品中心多一款可分配商品「通用积分」（1 元 = 1 积分）。

商户发给车主 **只走审批下单**，不开放商品中心直采。路径：

1. 按场景提审批（如新车返利）→ 导入手机号 → 上传凭证 → 审核通过  
2. 审批记录点「权益下单」→ 先选积分 → 再选通用积分或专用券（专用券再绑具体商品）  
3. 收银台用已充值账户余额支付（商品费 + 该商品手续费）  
4. **支付成功即入账**到名单手机号，C 端打开就能兑，没有待领取  

| 商户选择 | 买的商品 | 费率 | 发到手机号 | 车主接下来 |
|---|---|---|---|---|
| 通用积分 | 新商品「通用积分」 | 3%，全部商户承担 | 通用积分 | 积分专区兑福多多商品 |
| 专用券 | 原权益商品（通用金 / 支付宝通用券 / plus / 微信立减金，一次一种） | 合同费率（如 8%），可拆商户/用户，合计等于合同费率 | 只能兑这一种的专用额度 | 权益专区一次兑成金/券，再去对应板块使用 |

审批名单手机号 = C 端账号。

---

## 必须隔离

| | 专用券 | 通用积分 |
|---|---|---|
| 商户买的 | 原权益商品 | 新商品「通用积分」 |
| 用户能兑 | 仅绑定的那一种金/券 | 积分专区福多多商品 |
| 履约 | 自有 | 福多多 |
| 兑换后 | 结束，不能退 | 可整单退货退款，回积分并通知福多多 |
| 商户「用户积分」「兑换订单」 | 不记 | 只记这个 |

不能用同一个余额字段既扣专用券又扣福多多。

---

## C 端

入口在会员服务，积分商城在专属福利上方。发放后已在账上，点进入就进商城。

- **权益专区**：有专用额度才能兑，一次兑完；兑成后点「去使用」进通用金或我的权益。不能退。  
- **积分专区**：福多多商品。一次只用一种支付：通用积分 **或** 通用金 **或** 一张券。  

通用积分自发放成功日起 **90 天**有效，界面展示有效期至和即将到期。到期未使用的批次作废。

兑成的金/券从会员服务「通用金 / 我的权益」也能进去用。金/券本身有效期仍按该权益商品（现网多为 90 天）。

---

## 商户后台本期菜单

积分商城下：

- **用户积分**：只记通用积分。列表：用户、余额、15 天内到期。明细：发放批次 + 有效期至。不要待领取、不要专用券、不要调账。  
- **兑换订单**：只记通用积分兑福多多。已完成可整单退货退款。不能退一笔里的一部分；多笔可以分别退。不要专用券兑换单。  

积分专区选品改价改库存在福多多，商户后台不做。

审批「权益下单」由直接选权益商品，改为先选积分再选通用/专用。中台继续配通用积分这件商品和 3% 费率。

---

## 和福多多怎么对（扣积分的时序）

用户点确认兑换时要做两件事：扣账上的通用积分，以及通知福多多发货。  
**时序** = 这两步谁先谁后。

要求：**福多多下单成功后再扣积分**。若已经扣了但对方失败，必须把积分加回去。不要「积分扣了、货没发」。

退款：整单退，可退多笔不同订单；不支持部分退。退回积分沿用原批次剩余有效期。专用券兑换不走福多多。

对账用双方订单号关联。

---

## 计价

- 1 积分 = 1 元。采购体量 = 名单人数 × 导入体量。  
- 通用积分应付 = 商品金额 × 1.03。用户兑换不再扣这 3%。  
- 专用券：商户应付 = 商品金额 × (1 + 商户承担比例)；用户承担部分在兑成金/券时从到账金额扣。  
- 用通用金或券兑积分专区，按面值 1:1，不再加收一层商户手续费。  

---

## 关键账本

- 商户采购单：关联审批批次、商品（通用积分或某专用券商品）、名单、金额、手续费。  
- 用户通用积分账户：手机号、可用余额、各发放批次及有效期至。流水：发放入账、兑换扣减、退款退回、过期作废。  
- 用户专用额度：手机号 + 权益商品；与通用积分隔离。  
- 通用积分兑换单：福多多商品、消耗、支付手段、状态、对方单号。  
- 专用券兑换单走自有履约，不进「兑换订单」菜单。
